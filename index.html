RA81 OpenWrt package repositories

Package repositories of the lutvzn/RA81OpenWRT firmware for the Xiaomi Redmi AX3000 (RA81): the kernel modules and other packages of each release. They only install on an image of the same release, which already lists its repository in /etc/apk/repositories.d/distfeeds.list, so apk update && apk add kmod-<name> is all that is needed.
